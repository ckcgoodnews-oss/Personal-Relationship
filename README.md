# Personal Relationship With Jehovah

## 28-day personal Bible study website

**Theme:** Why Is a Personal Relationship With Jehovah Important?

A free, self-contained, mobile-friendly study site designed for 10 minutes a day. It includes 28 lessons in 4 weeks, New World Translation links, Watchtower Online Library research readings, reflection prompts, a 10-minute study timer, a progress tracker, and private journal notes saved in your device's browser.

## Publish using GitHub Pages

Repository: https://github.com/ckcgoodnews-oss/Personal-Relationship

1. Open the repository in GitHub and use **Add file → Upload files** (for an empty repository, choose **uploading an existing file**).
2. Upload **index.html**, **README.md**, and **.nojekyll** at the repository's top level, not in a subfolder.
3. Choose **Commit changes** to the `main` branch.
4. Go to **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch** as Source.
6. Set Branch to **main**, folder **/(root)**, then **Save**.
7. After GitHub Pages deploys, open https://ckcgoodnews-oss.github.io/Personal-Relationship/

## Important privacy note

Daily notes and completion checkmarks are kept in the browser's local storage, **not on GitHub**. They are private to that device/browser, do not sync across phones or computers, and can disappear if browser site data is cleared. Use **Export all notes** regularly to save a copy of your journal. The website itself is public.
